# Jarvis

Jarvis is a personal AI assistant built using Python. It integrates voice recognition and performs multiple tasks, such as sending emails, opening websites, and fetching real-time data.

## Features
- Voice commands for task execution
- Web scraping for current news/weather
- Task automation (e.g., reminders, email sending)

## Requirements
- Python 3.x
- `SpeechRecognition`, `pyttsx3`, `requests`, `pyaudio`, `sqlite3`, etc.
